# 勤務カレンダー作成ツール

4月〜翌年4月（13か月）の勤務カレンダーを作成し、A4で印刷するためのツールです。
`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで使えます。インストールは不要です。

## 使い方

1. 作成ページ（https://soutsu.github.io/JobCalendar/ ）を開く
2. **年度** を選ぶ（例：2027年4月 〜 2028年4月）。保存済みの年度ならその内容が開きます
3. **タイトル／サブタイトル** を入力（タイトルは年度から自動入力。サブタイトルは前の年度から引き継ぎます）
4. 日付をクリック（タップ）して **出勤（黒）⇄ 休日（赤）** を切り替える
   - 土曜・日曜・祝日（振替休日・国民の休日を含む）は最初から休日（赤）になっています
   - 手動で切り替えた日は画面上で太字になります（印刷時は通常の太さ）
   - 日付にマウスを乗せると祝日名が表示されます
5. **保存** を押す → その年度のカレンダーがブラウザ内に保存され、同じスマホ・PCの閲覧ページに反映されます
   - 保存状態は「✓ 保存済み」「● 保存していない変更があります」で表示されます
   - 作成ページは開くたびに保存済みの内容（閲覧ページと同じ）から始まります。保存せずに移動・終了した変更は残りません（移動時・終了時には確認が出ます）
6. **印刷・PDF** でA4縦1枚に印刷（プリンタに「PDFに保存」を選べばPDFになります）
   - 印刷設定の「余白」は「なし」または「デフォルト」、「倍率」は100%にしてください
   - 「背景のグラフィック」にチェックを入れると月番号の赤い箱が印刷されます

### 他のスマホやPCへ移す（ファイルの書き出し・読み込み）

保存先はブラウザ内なので、別の端末で見るときだけファイルを使います。

1. 作成ページで **ファイルに書き出し** → `work-calendar-2026.json` のような年度ごとのファイルができます
2. そのファイルを相手の端末に送る（LINE・メールなど）
3. 相手の端末の閲覧ページ（または作成ページ）で **ファイルから読み込み** を押して選ぶ
   - 閲覧ページで読み込むと、その年度としてすぐ保存・表示されます

## スマホでの編集

作成ツールはスマホにも対応しています（https://soutsu.github.io/JobCalendar/ をスマホで開く）。
画面幅が狭いと自動で月を縦に並べた表示になり、各月の出勤日数・休日日数も表示されます。
印刷・PDF は、スマホから行ってもPCと同じA4レイアウトになります。

## 表示言語（日本語 / සිංහල / English）

作成ページ・閲覧ページとも、上部の帯の選択欄で表示言語を切り替えられます。
選んだ言語はブラウザに記憶され、両方のページで共通です（初回はブラウザの言語設定に合わせます）。

- 曜日・祝日名・ボタン・説明文が切り替わります。印刷も選択中の言語の曜日で出力されます
- タイトルが自動入力のままなら、言語に合わせて表示が変わります（日本語は令和表記付き）
- 自分で入力したタイトル・サブタイトルはそのまま表示されます
- 翻訳は `i18n.js` にまとめてあります。訳の修正はこのファイルだけで済みます
- ローカルでファイルを開いて使う場合は、`common.js`・`i18n.js` も同じフォルダに置いてください

## 補足

- 祝日は現行の祝日法のルールで自動計算しています。法改正や臨時の祝日があった場合は、クリックで調整してください。
- 画面上部の「区間合計」に出勤日数・休日日数が表示されるので、見直しの際にご利用ください。

## スマホ閲覧用ページ（viewer.html）

月を縦に並べた、スマホで見るための閲覧専用ページです。GitHub Pages で公開し、スマホのホーム画面にアプリとして追加して使います。

- 閲覧ページ：https://soutsu.github.io/JobCalendar/viewer.html
- 作成ツール：https://soutsu.github.io/JobCalendar/ （PCからWeb上でも使えます）

### 初回のみ：GitHub Pages を有効にする
1. GitHub のリポジトリページ → **Settings** → 左メニュー **Pages**
2. 「Build and deployment」の **Source** を「Deploy from a branch」にする
3. **Branch** で `claude/affectionate-knuth-blykeo`（既定のブランチ）と `/ (root)` を選んで **Save**
4. 1〜2分待つと、上記URLで開けるようになります

### スマホでの設定
1. スマホの Chrome で閲覧ページのURLを開く
2. Chrome のメニュー（︙）→ **ホーム画面に追加**（または「アプリをインストール」）
3. 以降はホーム画面のアイコンから起動。電波が無くても表示できます
   - ネットにつながっていれば起動のたびに最新版を読み込むので、ページの更新はすぐ反映されます（再インストール不要）

### 使い方
- 開くと今年度のカレンダーが表示されます。**‹ ›** ボタンで保存済みの他の年度に切り替えられます
- **今月** ボタンで今月の位置へジャンプします（今日の日付は丸で囲まれます）
- 日付をタップすると「9/23（水）秋分の日・休日」のように詳細が表示されます（祝日には赤い点が付きます）
- 各月の見出しに、その月の出勤日数・休日日数が表示されます
- 同じ端末の作成ページで「保存」すると、自動で反映されます
- カレンダーのデータは端末のブラウザ内にのみ保存され、インターネット上には送信・公開されません
